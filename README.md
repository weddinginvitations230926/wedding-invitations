# Приглашение — Temur & Shirin

22 октября 2026, Самарканд, Restoran Marjon.

## Как опубликовать (GitHub Pages)

1. Создайте новый **публичный** репозиторий, назовите его `temur-shirin`.
2. Add file → Upload files → перетащите **содержимое** этой папки
   (`index.html`, папку `img`, `og.jpg`, `.nojekyll`) → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу
   `https://weddinginvitations230926.github.io/temur-shirin/`

Адрес для превью в WhatsApp и Telegram уже прописан в шапке `index.html`
(строки `og:url` и `og:image`). Если назовёте репозиторий иначе — поправьте их.

## Что можно поменять

Все данные пары — в блоке `WEDDING` в конце `index.html`:
время сбора (`time`), расписание (`schedule`), порядок фотографий (`photos`),
музыка (`music` — файл `music.mp3` лежит рядом с `index.html`), куда уходят ответы гостей (`rsvp`, `whatsapp`).
Подробности — в README шаблона.
